Configurando um Servidor Caseiro Seguro

Recentemente, decidi reaproveitar um hardware antigo para criar um servidor de arquivos centralizado. A ideia era simples: ter um local seguro para backups e compartilhamento de mídia na rede local.

Por que usar Linux?

O Linux oferece uma estabilidade incomparável para esse tipo de tarefa. Além disso, o controle sobre os processos e a segurança é muito mais refinado.

"A simplicidade é o grau máximo de sofisticação." — Leonardo da Vinci

Para começar, instalei o Ubuntu Server e configurei o acesso SSH. Abaixo, um exemplo de como verificar as portas abertas no firewall:

# Verificando status do UFW
sudo ufw status verbose

# Permitindo SSH apenas da rede local
sudo ufw allow from 192.168.1.0/24 to any port 22
